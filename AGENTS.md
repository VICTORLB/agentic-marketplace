# AGENTS.md

Instructions for coding agents other than Claude Code (e.g. Codex). This repo's source of truth is
[`CLAUDE.md`](CLAUDE.md). Read it first and follow the same commands, architecture rules, non-negotiables
and definition of done.

Role prompts that work with any agent live in `.claude/agents/*.md`. The body of each file is a plain
system prompt for that role.
